# random-spell
This Application uses The Net Libram of Random Magical Effects version 2 and 1.2. It's purpose is simple, you ask it for random effects, and it gives you some. This gives 20,000 different magical effect options.

It's worth noting that the older version came from an older PDF, some characters have been mistranslated over time. The 10,000 effects from that version are still legible, but the DM might need to occasionally fill in some blanks or reroll.
